# FAZOO security hardening — October 2, 2026

OCR is temporarily disabled. Both conversion endpoints and the OCR asset proxy return HTTP 410, with no provider calls or file parsing. The database OCR recorder is disabled and its client/service privileges revoked. Existing documents remain downloadable; administrators can upload prepared Word/PDF documents. HTTP uploads are capped at 4 MB, originals uploaded directly to private storage at 20 MB, and photos at 8 MB. MIME restrictions apply in storage; prepared files also undergo signature checks. These checks are not malware scanning.

Privileged implementation helpers no longer accept direct anonymous/authenticated RPC calls. Guarded application RPCs remain available. Organization admins cannot assign the super-admin role or move memberships across organizations. Membership read policies no longer recurse. Deleting a membership also synchronizes or deactivates its profile to prevent stale access. Approved status is required for super-admin privileges. Membership requests are rate limited and cannot reactivate suspended accounts or modify privileged memberships. Rate counters are atomic, service-only at the RPC boundary, and the login/export/upload routes fail closed if the limiter is unavailable.

Staff MFA is required in the app, guarded database RPCs, table policies, and private storage policies. Deploy the enrollment/challenge page before applying the final require_staff_mfa migration. All staff roles enroll an authenticator when first signing in after rollout. BA/client sign-in continues as before. Lost authenticator recovery requires the project owner to verify the staff member's identity and remove that user's MFA factor through Supabase's account administration; the user can then enroll again. There is no client-side bypass or recovery secret in the repository.

Production scripts use per-request CSP nonces; OCR CDNs and unsafe-eval are removed. Downloads stay private and use short-lived signed URLs. Login redirects reject external/encoded/backslash destinations. CSV exports neutralize spreadsheet formulas.

Next.js and vulnerable dependency branches are upgraded with compatibility-preserving overrides. A small query-string compatibility patch preserves its CommonJS API when using the fixed ESM decode-uri-component release; mobile query parsing and xcode UUID APIs have regression coverage. Forge 1.4.0 has a pinned backport of the nested DigestAlgorithm element-count fix proposed in upstream PR https://github.com/digitalbazaar/forge/pull/1152. Its regression checks both valid and malformed RSA signatures. Package audit still lists GHSA-86w9-cpqp-85rv by version; security:check accepts only that exact advisory with the reviewed patch hash and passing regression. Remove the patch/exception after a verified fixed upstream release is available.

Required owner setting: enable leaked-password protection in Supabase Authentication settings. The connected management tools cannot update Auth configuration. This setting remains unresolved until dashboard access is available; do not label it enabled based on these migrations.

Validation: run pnpm security:check, workspace typechecks/tests, changed-file lint and the admin production build. Database regressions must attempt role escalation and helper execution as authenticated and roll back all changes. After rollout verify HTTP 410 on both conversion endpoints and the OCR asset route, sign-in headers/nonces, and staff AAL1 database rejection.
